    Maneras de mover las letras:

    1) Toca una letra para que salte al siguiente hueco libre.

    2) Pica en una letra ya colocada (cambiará a naranja) y:
        - vuelve a picar para de-seleccionar
        - toca otro destino válido (otra letra, un hueco o el cajón de sastre) para moverla o intercambiarla.

    3) Pulsa primero un hueco vacío y luego una letra para enviarla allí.

    4) Mantén pulsada una letra ya colocada (cambiará a lila) y arrástrala para insertarla y desplazar las otras letras a la derecha.

    Escanea para compartir
